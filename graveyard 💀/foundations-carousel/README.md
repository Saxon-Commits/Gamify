# Foundations Carousel

## What It Was
A visual carousel component that displayed the three foundation "projects" (To-Do, Habits, Guild) with swipeable cards showing level progress, XP bars, and background images.

## Why Archived
- Removed during Phase 1 of pruning plan
- Feature was not actively used by player
- HP/level system for foundation projects doesn't fit current game design
- Simplified Quest Log UI by removing this visual element

## Reuse Potential
- Could be reused for:
  - Portfolio projects showcasing different skill categories
  - Game collections or achievement showcases
  - Multi-project management apps
- Dependencies:
  - framer-motion (for animations and drag gestures)
  - lucide-react (for icons)
  - Project objects with: id, name, hp, maxHp, backgroundImage, icon
